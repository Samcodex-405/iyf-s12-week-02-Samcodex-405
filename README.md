# 🎨 Week 2: CSS Fundamentals & Responsive Web Design

Welcome to **Week 2** of my journey through the **IYF WeCan Academy – Season 12 Practical Web Development Training**.

This week focuses on transforming my HTML portfolio into a visually appealing, well-structured, and fully responsive website using CSS. The goal is to move beyond basic HTML structure and create a professional user experience across different screen sizes.

## 📚 Lesson 3: CSS Fundamentals & Box Model

This lesson introduces the foundations of CSS and how to control the appearance, spacing, and typography of web pages.

### Tasks Completed

| Task | Description | Focus |
|---|---|---|
| 3.1 | CSS Setup & Basic Styling | CSS setup, resets and typography |
| 3.2 | Box Model Mastery | Content, padding, border and margin |
| 3.3 | Typography System | Font pairing and type scales |
| 3.4 | Color Scheme | CSS variables and color systems |

### Key Concepts Learned
- Linking external CSS stylesheets to HTML documents.
- Understanding CSS selectors and properties.
- Applying the CSS box model.
- Using `box-sizing: border-box` for predictable layouts.
- Creating consistent typography systems.
- Using CSS custom properties (`:root` variables).
- Building reusable color palettes.
- Styling links, buttons, headings and backgrounds.

---

## 📚 Lesson 4: Flexbox, Grid & Responsive Design

This lesson focuses on modern CSS layout techniques and building websites that adapt to different devices.

### Tasks Completed

| Task | Description | Focus |
|---|---|---|
| 4.1 | Flexbox Layout | Navigation, cards and footer layouts |
| 4.2 | CSS Grid Layout | Galleries, magazine layouts and project grids |
| 4.3 | Mobile-First Responsive Design | Responsive layouts and media queries |
| 4.4 | Polish & Refinement | Hover effects, transitions and accessibility |

### Key Concepts Learned
- Creating flexible layouts using CSS Flexbox.
- Understanding CSS Grid and two-dimensional layouts.
- Building responsive navigation bars.
- Creating reusable card layouts.
- Using mobile-first design principles.
- Applying media queries at different breakpoints.
- Improving user experience with transitions and hover effects.
- Adding visible focus states for keyboard accessibility.
- Preventing horizontal overflow on smaller screens.

---

## 📱 Responsive Design Breakpoints

The portfolio is designed to adapt to different screen sizes.

| Device | Screen Width | Layout |
|---|---|---|
| Mobile | 320px and above | Single-column layout |
| Tablet | 768px and above | Two-column layouts |
| Desktop | 1024px and above | Multi-column layouts |
| Large Desktop | 1280px and above | Expanded layouts |

## 🎯 Final Deliverable: Responsive Portfolio

By the end of this week, the portfolio should demonstrate:
